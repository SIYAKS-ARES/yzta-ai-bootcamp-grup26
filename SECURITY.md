# Security Policy

## Supported Versions

The following table shows which versions of this project are currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 5.1.x   | ✅ Supported        |
| 5.0.x   | ❌ Not supported    |
| 4.0.x   | ✅ Supported        |
| < 4.0   | ❌ Not supported    |

If you are using an unsupported version, we strongly recommend upgrading to a supported release.

---

## Reporting a Vulnerability

If you discover a security vulnerability in this project, **please report it responsibly** by following the steps below:

1. **Do not open a public issue.**
2. Instead, send a detailed email to **[msaidhuseyinoglu@gmail.com]** with the following:
   - Description of the vulnerability
   - Steps to reproduce
   - Affected versions
   - Any possible fixes or suggestions

3. We will respond to your report within **3 business days**. If the report is confirmed as valid, we aim to release a fix within **30 days**, depending on complexity.

4. Once fixed, we will:
   - Publish a new release
   - Credit you (optional)
   - Update this policy if necessary

Your help in responsibly disclosing vulnerabilities is greatly appreciated and helps keep this project secure for everyone.

---
